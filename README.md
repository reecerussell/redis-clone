# Redis Clone

I'm trying to learn C after many many years with .NET and Go, so I thought I'd write a Redis clone. This may or may not end up being a "redis clone" but, it will contain features to give me exposure to key C concepts and patterns.

In a world where coding agents are what you turn to for "hello world", my goal of this is to learn C the best I can without AI solving something for me. This means Stack Overflow, Reddit, and docs that seem to be lacking CSS. Having said that, in last resorts I will use Claude but as a review agent, rather that a "plz fix".
